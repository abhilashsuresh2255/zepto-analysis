# Zepto SQL Data Analysis Project

## 📌 Project Overview
This project analyzes product-level data from Zepto to extract insights related to pricing, discounts, stock availability, and product categories using SQL.

## 🛠 Tools Used
- PostgreSQL
- pgAdmin 4

## 📊 Key Analysis Performed
- Count of total products
- Sample data exploration
- Detection of NULL values
- Discount analysis
- Stock availability insights

## 🧠 Key Insights
- Identified missing values in multiple columns
- Analyzed discount patterns across categories
- Evaluated stock availability trends

## 📁 Files
- zepto_project.sql → Contains all SQL queries
- zepto_backup.sql → Full database backup

## 🚀 How to Use
1. Import the backup file into PostgreSQL
2. Run queries from zepto_project.sql using pgAdmin 4
